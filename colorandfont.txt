1.2 FONT FAMILIES & USAGE HIERARCHY
------------------------------------

1. 'Outfit', sans-serif
   - Category: Display Sans-Serif
   - Weights: 400, 500, 600, 700, 800, 900
   - Purpose: Primary heading and brand typography.
   - Applications:
       * All Page Headings (h1, h2, h3, h4)
       * Brand wordmark and logos (.brand, .nav-logo)
       * Hero headlines and section banners
       * KPI metric numbers and analytic counter cards
       * Modal titles and stage headers
       * System Tour role guides

2. 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
   - Category: Precision Neutral UI Sans-Serif
   - Weights: 400 (Regular), 500 (Medium), 600 (Semi-Bold), 700 (Bold)
   - Purpose: Core application user interface and body typography.
   - Applications:
       * Body text, paragraph content, descriptions
       * Complaint tables, column headers, cell records
       * Form inputs, textareas, select menus, checkboxes
       * Navigation items, tab labels, action buttons
       * Tooltips, popovers, and badge labels

3. 'Montserrat', sans-serif
   - Category: Geometric Heavy Display
   - Weights: 800 (Extra-Bold), 900 (Black)
   - Purpose: Championship Team Showcase poster impact branding.
   - Applications:
       * Championship Team Page Title: SUPPORTNOVA (.tp-brand-title)
       * Poster card vertical badge tags (.tp-vert-main)
       * Member name plates on poster cards (.tp-card-name)

4. 'Alex Brush', 'Dancing Script', cursive
   - Category: Elegant Hand-Lettered Script
   - Weights: Regular (Alex Brush), 700 (Dancing Script)
   - Purpose: Calligraphic signature lettering.
   - Applications:
       * Team Poster signature "Team" display script (.tp-script-team)
       * Team poster graphic signature flourish

5. 'DM Sans' & 'Manrope', sans-serif
   - Category: Modern Clean Sans-Serif
   - Weights: 400, 500, 600, 700 (DM Sans) / 500, 600, 700, 800 (Manrope)
   - Purpose: Base layout fallback and legacy dashboard components.

6. 'SFMono-Regular', Consolas, 'Courier New', monospace
   - Category: Fixed-Width Monospace
   - Weights: 400, 500, 600
   - Purpose: Technical data, code previews, and strict alignment tokens.
   - Applications:
       * Complaint Reference IDs (e.g., #CMP-2026-8910)
       * SLA Countdown Timers and timestamps
       * JSON payload and API token inspectors
       * Audit trail cryptographic log hashes
       * Metric badges and code snippets


1.3 TYPOGRAPHY SCALE & SPECIMEN
--------------------------------
- Hero / Poster Title:     36px - 56px  | Weight: 800/900 | Font: Outfit / Montserrat
- Script Signature:        54px - 72px  | Script          | Font: Alex Brush / Dancing Script
- Primary Section H1/H2:   24px - 32px  | Weight: 700/800 | Font: Outfit
- Subsection / Card H3:    17px - 20px  | Weight: 600/700 | Font: Outfit
- Body & Table Standard:   13.5px - 15px| Weight: 400/500 | Font: Inter
- Small Labels & Dim Meta: 12px - 13px  | Weight: 500/600 | Font: Inter
- Eyebrow / Micro Caps:    10px - 11px  | Weight: 700     | Font: Outfit / Inter (tracking: 0.16em)
- Monospace Data Badges:   11px - 13px  | Weight: 500/600 | Font: Consolas / SFMono
